# The Effect of LLM Assistance on Diagnostic Accuracy: A Systematic Review and Meta-Analysis

The analysis examines the effect of large language model (LLM) assistance on physicians’ diagnostic accuracy. The repository includes the coded study data (see folder "Data") and the scripts used to generate the reported analyses and figures. The analyses were conducted in R, primarily using the `metafor` and `clubSandwich` packages.
